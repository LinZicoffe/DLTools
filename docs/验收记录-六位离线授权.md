## 已交付行为

- 左侧新增“离线授权”，默认仍进入固件烧录；页面缓存输入、结果和状态。
- 新建客户／设备档案，分配独立 32 字节随机密钥；重命名不改变密钥或设备标识。
- 输入六位 ASCII 申请码，离线生成六位授权码，保留前导零；修改输入或档案时清空旧结果，点击后才复制授权码。
- 档案整体使用 Windows 当前用户 DPAPI 保存，界面只绑定非密钥元数据。
- 创建 `.dlauth` 加密备份，密码确认后使用固定参数的 PBKDF2-HMAC-SHA256 和 AES-256-GCM；恢复先认证、预览，再经确认合并提交。
- 同设备标识不同密钥拒绝覆盖；确认期间库被其他实例修改时拒绝使用旧恢复计划；损坏库恢复前保留原文件副本。
- 档案操作登记全局任务宿主，与烧录和打包互斥；取消及关窗等待真实任务结束和原子保存边界。
