# 评审记录 — 高速下载

基线 `b3c6246`，分支 `main`，评审日期 2026-11-09。F01–F05 一次性交付，逐待办自评 + 项目级自查如下。

## F01：纯逻辑层（模型 / 校验 / 探测 / 分段 / 日志 / 限速 / 设置）

Reviewer A（正确性）：
- `RangeProbe.TryParseContentRange` 覆盖 `bytes 0-0/N`、`*/总长未知`、负值、end<start、非数字、无斜杠等 12 类输入；`filename*=UTF-8''` 优先于 `filename=` 且非 UTF-8 charset 回退——与 TDM 观察到的 RFC 5987 行为对齐。
- `DownloadJournal` 原子替换写（Guid.tmp + File.Replace + flushToDisk），损坏抛 IOException 保留现场、URL 不匹配返回 null 不删文件、分段越界/合计超总长均拒绝。处置：通过。
- `DownloadSettingsStore` 命名 Mutex + 原子写 + 越界钳制 + 损坏抛异常，仿 PackagingProfileStore；独立子目录不碰烧录偏好。

Reviewer B（安全）：
- `DownloadUrlGuard`：全 URL 仅 http/https + 拒绝 userinfo 内嵌账号；清单/节点另要求 https 且 host 解析结果全部为公网（IPv4 各私网段、IPv6 环回/链路本地/fc00::/7、IPv4 映射地址均判定）；测试用 IP 字面量避免 DNS 波动。
- 处置：通过（`FilterMirrorUrls` 静默跳过非法节点而非整体失败，理由是清单可能同时服务内外网环境，已在注释说明）。

Reviewer C（可测性）：限速器时钟/延时双注入、引擎传输接口化（IpScan 可注入委托模式的接口化），假传输夹具复用。处置：通过。

## F02：传输与引擎

Reviewer A：
- 分段路径完整链：探测（bytes=0-0）→ journal 续传判定（URL/ETag/总长/分段连续性四重校验）→ 预分配 SetLength → worker 拉段队列（先完成者取下段）→ 终验（长度+SHA-256）→ FlushToDisk+Dispose → 存在即改名 → Move → 删日志。
- 重试/退避：0.5s·2ⁿ 封顶 30s、最多 5 次/段；429 尊重 Retry-After（取与指数退避较大值）；403/404/410 终态；非首段 200 → RangeIgnoredException → 原地降级单流；30s 看门狗（Task.WhenAny 包 ReadAsync）；EOF 提前结束按段重试。
- 自查修复 ①：SHA 校验原在写句柄（FileShare.None）未释放时读临时文件 → IOException；改为先 FlushToDisk+Dispose 再校验（长度核对随之改 FileInfo）。
- 自查修复 ②：分段完成报告被 100ms 节流吞掉，暂停判定依赖迟到报告会拖到看门狗；分段完成改为立即上报（状态跃迁绕过节流），测试耗时从 30s 降到毫秒级。
- 处置：通过（13 项引擎行为测试全绿：多段合并、小文件单流、探测 200 降级、503 重试、429 换镜像、看门狗、截断续段、取消保日志、续传跳过已完成、ETag 变更重下、SHA 失败保留现场、大小不符、防盗链、并行分段互锁证明）。

Reviewer B：
- HTTP/1.1 钉死（RequestVersionExact）防 H2 单连接挤压，注释说明理由；AutomaticDecompression=None 防 Content-Range 与实体错位；HttpClient.Timeout=Infinite，卡死交给看门狗；UA 改 ASCII（自查修复 ③：中文产品名被 HttpHeaderParser 拒绝）。
- 处置：通过。

## F03：调度与页面

Reviewer A：
- 槽位泵（PumpLocked）+ FIFO；暂停 = 取消令牌 + PauseRequested → 引擎返回时落 Paused；取消/重试/移除状态机；移除运行中任务抛 InvalidOperationException 提示先暂停。
- 自查修复 ④：引擎失败以返回值（FromFailure）而非异常呈现，调度器原一律标 Completed；改为按 result.Completed 分流 Completed/Failed。CancelAll 把 Queued 一并置 Paused，保证退出后无活动任务。
- 关窗：host 与下载两路判定合并一次确认，下载文案说明保留续传记录；确认后 await host.CurrentTask + scheduler.CancelAllAndDrainAsync() 双排空；App.OnExit 10 秒兜底 Wait。处置：通过。

Reviewer B（UI 规范）：OneWay 计算列（StateText/ProgressPercent/SizeText/SpeedText/EtaText 均经 NotifyPropertyChangedFor）；后台事件全部 Dispatcher.InvokeAsync 后改集合；共享样式 PageBgBrush/RoundedProgressStyle/LogConsoleStyle 沿用；侧栏"IP 扫描"按钮补底边距、新按钮按既有 DataTrigger 高亮。处置：通过。
